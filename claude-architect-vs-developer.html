Claude Certified Architect vs Developer: which Anthropic certification should you take first?

Anthropic's 2026 certification track has three exams: Claude Certified Developer (CCDV-F), Claude Certified Architect Foundations (CCA-F), and Claude Certified Architect Professional (CCAR-P). Which one to start with depends entirely on whether you build with the Claude API day-to-day, or design the systems around it.

By ExamFastTrack Updated 2026 9 min read

All three exams test the same underlying platform — the Messages API, agents, tool use, MCP, Claude Code — but from different vantage points. CCDV-F is hands-on-the-API developer knowledge. CCA-F is architectural decision-making for agent systems. CCAR-P is CCA-F's production-grade sequel: governance, evaluation and stakeholder scenarios at scale.

The quick verdict

  • Choose CCDV-F if you write code against the Claude API: applications, integrations, tool use, model selection, prompt and context engineering.
  • Choose CCA-F if you design agent architectures — agentic loops, multi-agent orchestration, MCP and tool design, Claude Code workflows — even if you don't ship the code yourself.
  • Add CCAR-P once CCA-F is done and you're responsible for production systems: integration at scale, governance and risk, evaluation, and stakeholder communication.

CCDV-F: the hands-on developer credential

Claude Certified Developer – Foundations is built for people writing the code: calling the Messages API, handling streaming and prompt caching, wiring up the Batch API, choosing between models on cost and latency, building agent and tool-use loops, and following security best practices.

  • Format: 53 questions, 120 minutes, pass at 720/1000.
  • Heaviest domains: Applications & Integration (33.1%), Model Selection & Optimization (16.8%), Agents & Workflows (14.7%).
  • Feels like: a practical API exam — status codes, request/response shapes, cost and latency trade-offs.
  • Best for: backend and full-stack developers, AI engineers shipping Claude-powered features.

CCA-F: agentic architecture and design decisions

Claude Certified Architect – Foundations steps back from implementation details to architectural judgement: when to use a workflow vs. an autonomous agent, how to design coordinator-subagent systems, how to structure MCP servers and tools, how to configure Claude Code for a team, and how to keep long-running agents reliable as context fills up.

  • Format: 60 questions per exam across 5 full-length exams (300 questions total), pass at 720/1000.
  • Heaviest domains: Agentic Architecture & Orchestration (27%), Tool Design & MCP Integration (18%), Claude Code Configuration & Workflows (20%), Prompt Engineering & Structured Output (20%).
  • Feels like: a judgement exam — several answers "work," you pick the one that best fits the architecture's constraints.
  • Best for: solution architects, tech leads, and senior engineers designing agent systems rather than only implementing them.

CCAR-P: the production and governance sequel

Claude Certified Architect – Professional assumes CCA-F-level fluency and adds the concerns that show up once an agent system is live: multi-team integration, evaluation and cost/latency optimization at scale, compliance and guardrails (HIPAA, GDPR, FedRAMP-style constraints), and communicating architectural trade-offs to non-technical stakeholders.

  • Format: 63 questions per exam across 6 full-length exams (378 questions total), pass at 720/1000.
  • Heaviest domains: Integration (19%), Solution Design & Architecture (17%), Evaluation, Testing & Optimization (16%), Governance, Safety & Risk Management (14%), Stakeholder Communication & Lifecycle Management (14%).
  • Feels like: scenario-heavy case studies — a named company, a scale constraint, and a decision to defend.
  • Best for: architects and staff/principal engineers accountable for production agent systems, not just their initial design.
These aren't competing exams — they stack. A common 2026 path is CCDV-F for API fluency, then CCA-F for architecture, then CCAR-P once you own production outcomes. The only real question is where you should start.

If you want more than one, what order?

Coming from a hands-on developer role

Start with CCDV-F. It matches what you already do day-to-day, builds confidence fast, and gives you the API-level fluency that both architect exams assume you already have.

Already designing systems, not just implementing them

Go straight for CCA-F, then CCAR-P once you're accountable for a system in production. Skipping CCDV-F is fine if you're not writing the integration code yourself.

Common questions

Should I take Architect or Developer first?

If you write code against the Claude API day-to-day, start with CCDV-F. If you design agent architectures and make build decisions, start with CCA-F.

Is CCAR-P harder than CCA-F?

Yes. CCA-F covers core agentic architecture, MCP and Claude Code concepts; CCAR-P adds production concerns — governance, risk, evaluation and stakeholder communication at scale.

What are the passing scores?

All three 2026 exams — CCDV-F, CCA-F and CCAR-P — use a scaled passing score of 720/1000.

Do I need CCDV-F before CCA-F?

No, it's not a prerequisite. It helps if you want deep API fluency first, but architects who don't write the integration code themselves can start directly with CCA-F.
